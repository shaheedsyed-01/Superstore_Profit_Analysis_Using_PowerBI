# 📊 Superstore Profit Analysis

A data analysis and visualization project focused on analyzing the **Superstore dataset** to understand sales, profit, product, customer, and regional performance.

The project includes data cleaning using Python and an interactive dashboard developed in Power BI.

---

## 🛠️ Tools & Technologies

- **Python** – Data cleaning and preprocessing
- **Pandas** – Data manipulation and cleaning
- **Power BI** – Data visualization and dashboard development
- **Power Query / DAX** – Data transformation and analysis

### 📊 Power BI Dashboard

**`Superstore_Profit_Analysis.pbix`**

The Power BI dashboard provides interactive analysis of:

- Total Sales
- Total Profit
- Total Orders
- Quantity Sold
- Profit Margin
- Category and Sub-Category performance
- Regional and State-wise performance
- Customer Segment performance
- Sales and Profit trends

Interactive filters and visualizations are provided to explore the data from different perspectives.

---

### 📂 Dataset

**`Superstore_Dataset.csv`**

This file contains the cleaned dataset used for the project.

The dataset includes information such as:

- Order details
- Customer information
- Product information
- Sales
- Quantity
- Discount
- Profit
- Region
- State
- Category
- Sub-Category
- Order and Ship Dates

---

### 🐍 Data Cleaning Script

**`main.py`**

The Python script is used to clean and preprocess the raw Superstore dataset before using it for analysis and visualization.

The data cleaning process includes:

- Loading the raw dataset
- Checking and handling missing values
- Removing duplicate records
- Correcting data types
- Formatting date columns
- Cleaning and standardizing data
- Saving the cleaned dataset for Power BI analysis
